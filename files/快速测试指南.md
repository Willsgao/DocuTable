# 智能缓存功能 - 快速测试指南

## 🚀 测试步骤

### 测试1：首次处理（生成缓存）

1. **启动程序**
   ```bash
   cd f:/wills/my_softwares/DocuTable
   python main.py
   ```

2. **选择PDF文件**
   - 点击"选择PDF文件"按钮
   - 选择任意一个PDF文件

3. **观察标签颜色**
   - 如果是首次处理，应该显示：
     ```
     filename.pdf [待解析]   ← 红色
     ```

4. **开始处理**
   - 点击"开始处理"按钮
   - 等待处理完成

5. **检查缓存文件**
   - 查看 `mid_data/` 目录
   - 应该能看到新生成的缓存文件（`.json`格式）

6. **观察状态栏**
   - 处理完成后，状态栏应该显示：
     ```
     处理完成！
     ```

### 测试2：自动加载缓存

1. **重新启动程序**
   - 关闭程序，重新启动

2. **选择同一PDF**
   - 再次选择刚才处理的PDF文件

3. **观察自动加载**
   - **应该自动加载**，不弹出任何对话框
   - 文件标签显示：
     ```
     filename.pdf [从缓存加载]   ← 蓝色
     ```
   - 状态栏显示：
     ```
     已从缓存加载数据 (缓存时间: 2026-05-10 19:30:00)
     ```

4. **检查数据完整性**
   - 表格数量是否正确
   - 数据是否完整

### 测试3：修改PDF后重新解析

1. **修改PDF文件**
   - 使用PDF编辑器修改PDF内容
   - 或者删除并重新复制PDF文件

2. **重新选择PDF**
   - 选择修改后的PDF文件

3. **观察缓存失效提示**
   - 应该弹出提示：
     ```
     缓存已失效
     发现该PDF的历史缓存数据，但PDF文件已被修改（哈希值不匹配）。
     
     请点击"开始处理"重新解析PDF。
     ```

4. **重新处理**
   - 点击"开始处理"
   - 完成后查看缓存文件时间戳是否更新

### 测试4：缓存管理界面

1. **打开配置页面**
   - 点击"配置"标签

2. **查看缓存统计**
   - 找到"💾 缓存管理"区域
   - 应该显示：
     ```
     共 X 个缓存文件，总大小 Y.YY MB，有效 Z 个
     ```

3. **查看缓存列表**
   - 应该看到所有缓存文件
   - 每个文件显示：
     - ✅/❌ 有效性状态
     - PDF文件名
     - 缓存时间
     - 文件大小
     - 表格数量

4. **刷新列表**
   - 点击"🔄 刷新列表"按钮
   - 列表应该更新

5. **删除单个缓存**
   - 在列表中选择一个缓存
   - 点击"🗑️ 删除选中"
   - 确认删除
   - 列表应该更新

6. **清空全部缓存**
   - 点击"⚠️ 清空全部缓存"
   - 确认删除
   - 所有缓存应该被删除

## 🐛 常见问题

### Q1: 为什么缓存没有自动加载？

**可能原因**：
1. PDF文件被修改过
2. 缓存文件被删除
3. 缓存验证失败

**解决方法**：
- 检查配置页面的缓存列表，看状态是 ✅ 还是 ❌
- 如果是 ❌，说明缓存已失效，需要重新解析

### Q2: 缓存文件太大怎么办？

**解决方法**：
1. 定期清理不需要的缓存
2. 使用"⚠️ 清空全部缓存"删除所有缓存
3. 或者手动删除 `mid_data/` 目录下的文件

### Q3: 想保留部分缓存怎么办？

**解决方法**：
1. 查看缓存列表，记录需要的PDF名称
2. 使用"清空全部缓存"删除所有缓存
3. 重新处理需要的PDF文件

### Q4: 缓存加载后数据不对怎么办？

**可能原因**：
1. PDF文件被修改
2. 缓存数据损坏

**解决方法**：
1. 删除该PDF的缓存（选中后点击"🗑️ 删除选中"）
2. 重新处理PDF

### Q5: 如何查看缓存内容？

**解决方法**：
1. 打开 `mid_data/` 目录
2. 找到对应的 `.json` 文件
3. 使用文本编辑器打开查看
