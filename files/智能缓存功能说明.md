# PDF表格处理系统 - 智能缓存功能说明

## 📌 功能概述

我已经为你的PDF表格处理系统添加了**智能缓存功能**，实现了：

1. ✅ **自动保存解析数据** - 处理完成后自动保存到本地缓存
2. ✅ **智能缓存验证** - 检测PDF文件是否被修改，自动判断缓存是否有效
3. ✅ **自动加载缓存** - 选择PDF时自动加载有效缓存，无需手动确认
4. ✅ **缓存管理界面** - 在配置页面查看、删除缓存
5. ✅ **UI状态提示** - 显示数据来源（从缓存加载 / 待解析）

---

## 🔧 技术实现

### 1. 增强的缓存数据结构

```python
{
    "pdf_info": {
        "path": "C:/path/to/file.pdf",
        "modified_time": "2026-05-10T19:29:00",    # PDF文件修改时间
        "file_hash": "a1b2c3d4e5f6...",             # PDF文件MD5哈希
        "file_size": 1048576,                      # PDF文件大小
        "cached_time": "2026-05-10T19:30:00"       # 缓存创建时间
    },
    "data": {
        "success": true,
        "tables": [...],
        ...
    }
}
```

### 2. 缓存验证机制

- **哈希验证**：计算PDF文件开头1MB和结尾1MB的MD5哈希值
- **大小验证**：检查PDF文件大小是否变化
- **时间验证**：记录并比较文件修改时间

### 3. 智能加载流程

```
选择PDF文件
    ↓
检查缓存是否存在？
    ├─ 否 → 显示"[待解析]"，等待用户点击处理
    │
    └─ 是 → 验证缓存是否有效？
                ├─ 有效 → 自动加载缓存，显示"[从缓存加载]"
                └─ 无效 → 提示"缓存已失效"，显示"[待解析]"
```

## 📁 缓存文件存储

缓存文件保存在 `mid_data/` 目录：

```
mid_data/
├── 建设银行年度报告_2026-05-10_a1b2c3d4e5f6.json
├── 工商银行年报_2026-05-09_d7e8f9a0b1c2.json
└── ...
```

命名规则：`{PDF文件名}_{MD5哈希前16位}.json`

## ⚙️ 使用方法

### 1. 自动工作流程

1. **首次处理**：
   - 选择PDF文件 → 点击"开始处理" → 数据保存到缓存

2. **再次打开同一PDF**：
   - 选择PDF文件 → 自动检测到有效缓存 → 直接加载结果

3. **PDF被修改后**：
   - 选择PDF文件 → 检测到缓存失效 → 提示重新解析

### 2. 手动管理缓存

1. **查看缓存**：
   - 打开「配置」页面 → 查看"💾 缓存管理"区域

2. **删除单个缓存**：
   - 配置页面 → 选择要删除的缓存 → 点击"🗑️ 删除选中"

3. **清空所有缓存**：
   - 配置页面 → 点击"⚠️ 清空全部缓存" → 确认删除

4. **强制重新解析**：
   - 方法1：删除对应缓存 → 重新选择PDF
   - 方法2：选择已解析过的PDF → 询问时选择"是"重新解析

## 🐛 故障排除

### 缓存未自动加载？

1. 检查缓存是否有效（配置页面查看状态）
2. PDF文件是否被修改过（哈希值不匹配）
3. 检查 `mid_data/` 目录权限

### 想强制重新解析？

1. 在配置页面删除对应缓存
2. 或者选择文件时选择"重新解析"

### 缓存文件太大？

- 定期清理不需要的缓存
- 使用"⚠️ 清空全部缓存"功能

---

## 📝 注意事项

1. **缓存文件大小**：每个缓存文件包含完整的解析结果，可能占用较大空间
2. **PDF修改检测**：使用哈希验证，检测文件开头和结尾的变化
3. **缓存目录**：`mid_data/` 目录与程序在同一目录
4. **数据安全性**：删除缓存后无法恢复，请谨慎操作
