# 打包说明

## 打包步骤

### 1. 安装打包工具

在命令行中执行：

```bash
pip install pyinstaller
```

### 2. 执行打包

```bash
python build.py
```

打包过程可能需要 3-5 分钟，请耐心等待。

### 3. 打包结果

打包完成后，在 `dist/银行年报PDF解析工具/` 目录下会生成：

```
dist/银行年报PDF解析工具/
├── 银行年报PDF解析工具.exe    # 主程序
├── config/                    # 配置目录
├── pdf_history.json           # 历史记录
└── ... (其他依赖文件)
```

### 4. 分发使用

直接拷贝整个 `dist/银行年报PDF解析工具/` 文件夹到其他电脑即可运行。

**不需要安装 Python！不需要安装任何依赖！**

## 注意事项

1. **图标文件** - 如果需要自定义图标，准备一个 `.ico` 文件，放在项目根目录
2. **首次运行** - 可能会有杀毒软件误报，添加信任即可
3. **配置文件** - `config/config.json` 会在首次运行时自动创建
4. **API Key** - 需要在工具内重新配置豆包 API Key

## 打包选项说明

- `--onedir`: 打包成文件夹（推荐，便于管理和升级）
- `--onefile`: 打包成单个 exe（体积约 300MB+，启动较慢）
- `--windowed`: 不显示命令行窗口（GUI 程序推荐）

如需修改打包参数，编辑 `build.py` 文件。
