# 正常表契约（冻结版）

> 修改 `table_anomaly_rules.py` 前必读。未在本契约中列出的行为，不得擅自新增或删除。
> 契约变更须同步更新 `tests/anomaly_golden/` 并跑 `anomaly_change_guard verify`。

## 预处理

1. **删除全空白行、全空白列**后再质检（写回 `table.data`）。
2. 不再对「整列全空」报幽灵列（空列已删）。

## 表头区定义

1. **表头区** = 第一行数据之上的所有行（扫描全表找首行数据）。
2. **报告期/年份**（`2024年`、含「报告期」等）**不算数据行**，留在表头区。
3. **数据行**：序号列短整数；或实数（≥3 位/千分位）+ 文本；或 ≥2 个实数格。

## C1 表头

1. 数据列：数据区至少 1 格非空。
2. 有表头：表头区该列**任意一格非空文本**即算（含报告期、年份、项目名等）。
3. 唯一豁免：**第 0 列且为序号列**可无表头。

## C2 行类型（数据区）

每行须为以下之一：

| 类型 | 说明 |
|------|------|
| 数据锚点行 | 有序号或数值列有内容 |
| 折行续行 | 无数值；无序号；能接上锚点；仅标签列有字 |
| 小节行 | 有标签字；无数值列数据 |
| 空行 | 已删除，不参与 |

## C3 列性质

1. **数值列**：非法长文本报错；≤3 字短码允许 ≤12%。
2. **纯文本列**：仅长度不同、**同行邻列均有内容** → **不检查**长度/粘连（R01/R02/R03 跳过）。

## 必须检出的异常（丢失 / 粘连 / 错位）

| ID | 场景 |
|----|------|
| R02 | 短列吞序号、短列过长且长文本空+同行有数 |
| R04 | 数值格多 token |
| R05 | 数值列长文本杂质 |
| R08 | 邻列表头/数据错位（≥2 行） |
| R09 | 中间列孤立单格（非标签列） |
| R10 | **金额型数值与文本同格粘连**（如 `19,079,642 成都`）→ 重点可疑，`strict_review` |
| C02 | 行无法归类 |
| R01 | 长文本孤立片段（邻列有空白时才查长度类） |

### R10 细则

1. 扫描**数据区**全部非空格（不限数值列）。
2. 命中条件：同格内同时出现 **金额型数值**（千分位或 ≥4 位纯数字/百分比）与 **文本标签**（含汉字或字母）。
3. 不含：纯多数值（归 R04）；报告期/年份格；地址中常见的短整数（≤3 位且无千分位）。
4. 命中即 `needs_review=true`，并置 `strict_review=true`，异常分不低于 0.85。

## 表头缺失（单独归类，非质量异常）

| ID | 场景 | 归类 |
|----|------|------|
| C01 | 数据列无表头 / 无表头带 | `anomaly_class=missing_header`，`table_category=数据表(缺表头)`；**不**触发 `needs_review`（可续表/跨页合并候选） |

仅当 C01 与其他质量规则同时命中时，才进入 `needs_review`。
